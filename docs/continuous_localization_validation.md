# 継続性と精度の再調査（2026-09-28）

**常時・高精度の自己位置推定は未達。地図支持の残差や配信数は絶対位置精度ではない。**

## 採用した標準処理

- GPU格子探索後、支持点の面法線に沿う残差でSE(2)を連続最適化する。Eigenの3×3計算を最大2回、最大約1024点。Huber重みを使い、補正範囲は40mm・0.04rad以内。
- 法線・回転の情報行列が退化する観測を棄却する。単一壁や回転対称の点だけで3自由度の姿勢を確定しない。
- 初期全域探索にも支持数・支持率・方向・観測可能性を検査する。元の全点平均コスト条件も維持する。
- 観測オドメトリの間隔が250ms以下なら、地図測定の取得時刻へ状態を挿入して補正・再伝播する。欠落区間は補間しない。端点を使用する場合は、時刻差に対して5m/s・3rad/sの運動幅に相当する測定ノイズを加える。
- 通常の地図観測にも移動量検査を適用する（XYは0.1m+5m/s×dt、yawは0.1rad+3rad/s×dt）。支持点だけを根拠に数m飛ぶ候補を採用しない。
- 3観測での復帰確認は、設定した観測標準偏差の `2√2` 倍に整合させる。補正上限・観測ゲートは維持する。
- `map_only_updates:=true`（融合launchの標準）では、初期地図位置合わせ後、オドメトリが不健全・観測時刻に未到達の場合、地図測定時刻まで位置を保持して不確かさを増加し、通常ゲートで観測を更新する。未知のオドメトリ増分は作らず、再接続時に基準を設定し直す。
- RVizの標準比較点群は `/obstacle_cloud`（取得時刻補償後）。生の `/gn10/rviz_cloud` は手動で表示できるが、100msの取得期間による歪みが残る。Fixed Frameはmap。

既存の3状態EKFと側面距離による地図評価を維持する。FAST-LIO本体を変更せず、地図補正をFAST-LIOへ返さない。新しい外部ライブラリは追加していない。

## 切り替え可能な床面抽出（標準は無効）

`filter_params.adaptive_floor=true` では、最大1024点・48仮説の近水平RANSACから床面を推定し、GPUで平面からの距離を使って床点を除去する。
広い2方向の分布、100点以上、65%以上の支持、傾き・高さ・残差の制限を満たす場合だけ採用し、不成立時は従来の固定Z条件へ戻す。
点群のXYZと取り付けTFは変えない。取り付け角・高さを校正する機能ではない。

walkの初期・中盤・終盤7スキャンの床高さ差は約8–11mm、平面残差の標準偏差は約6mm。
固定Z=4cmの除去では床点が障害物側に最大295点（約4.5%）残った。
床の分類を改善する機能は実装したが、全区間の融合継続性は改善せず、標準には採用しない。

## 採用しなかった試験

### 短時間観測・高さ制限

`fallback_window_s:=0.02` では、初期位置合わせ後にオドメトリが欠落した場合、最後の20msの実測点を使用する。標準は0（無効）。
取得区間の中央を測定時刻とし、50msを超えるIMU欠落を補間せず実角速度で旋回補償する。
直前の地図観測から最大1.5mの局所探索も比較する。観測数は増えたが、停止や別の位置への対応が残った。
高さを0.85mに制限する試験でも同じ取得時刻の候補に数mの差があり、正解がないため採用していない。標準の高さ上限は100m。

### 有限3D表面・速度誤差推定

側面だけの距離では机・教壇の上面が不一致になる問題を調べ、有限の箱・円柱表面を試した。
上面はXY法線を持たないため、局所位置推定の支持数・ランキングに数えない版も試した。
しかしCADの箱は机・椅子の脚などの実物形状まで表現せず、全区間の継続性が悪化したため、この表面変更は戻した。上面を含むモデルの改善は未解決。

## 入力と残る制限

walk/gameともLiDAR取得時刻に最大約2秒、IMUに最大約1.16秒の欠落が実在する。
センサーのヘッダーは記録時刻より約13–14秒古い。取得時刻順の再生で順序・バーストは改善できるが、欠けた観測は復元できない。
FAST-LIOの速度・高さのドリフトも確認した。ただし全ての不一致をこれだけで説明できるとは断定していない。

9テストが全て合格。床面推定、GPUの平面距離分類とXYZ保持、面への精密化、単一壁の棄却、動的外れ値、時刻選別、IMUの補間禁止、測定時刻での補正、地図のみ更新と再接続を含む。

絶対精度と初期候補の正否を確認するには、独立した初期位置・位置ラベルが必要。
欠測中を含む常時の高精度を検証するには、欠落のないLiDAR/IMU入力、または独立した位置観測が必要。
現状の全区間試験には長い停止が残り、要求の達成とは報告しない。
