# 競技フィールドCAD図と照合用地図の監査

対象: `robocot26_field421.pdf`（平面・側面図1ページ、イメージパース2ページ）、
`高専ロボコン2026ルールブック0415.pdf`（2.1節、5.3–5.6節）と
`config/nhk2026_map.json`。2026年9月26日に更新。

このリポジトリのRViz設定では、地図表示はOccupancyGridの`/static_map`ではなく
MarkerArrayの`/field_map_markers`である。通常設定ではJSONの35個の箱・円柱を
読み込み、各箱の`param1`/`param2`を半寸法として表示する。
`VISUAL_BOX`の4個は床面に置かれるフェンス土台で、地面除去後の点群との照合には
含めない。立上り4個を照合に使う。

フェンス土台の中心はx=±5.325 m、y=±5.775 m。立上りの内面をCADの
競技領域端x=±5.25 m、y=±5.70 mに置いた。断面図の内外の向きは
平面図と併せて解釈しているため、現物の立上り面は実測で確認する。

JSONのコントロールステーションの机は同ステーション付近、補充スポットの机は
同スポット付近に
置かれている。ルールブック5.6節に同じ机を使うと明記されているため、
地図の机8箱は個数と外接寸法が合う。ただし実物の机には脚と棚があり、
椅子にも脚と背もたれがある。現在の地図は床から上端まで埋まった箱で
近似する。バケツの取っ手・テーパー、旗の布・ポールの詳細形状も
外接寸法だけでは再現できない。

赤側の台座や旗・椅子・机には、実物より大きい白いカッティングシートの寸法も
併記されている。地図は床材・シート・スタートゾーンを表現していない。
赤側のシート寸法を障害物本体の寸法として置き換えてはならない。

## 結論と適用範囲

**記載された名目寸法と配置は、上表の範囲で一致するよう修正した。**
一方、全物体の表面が「完全一致」する3D CADモデルではない。
図面・ルールブックに指定のない細部を推測で作らず、軽量な箱・円柱モデルを保つ。

図面には造作物の施工誤差があり得る旨が明記されている。CADとJSONを一致させても
実フィールドとの一致は別途測量が必要。特にフェンスの立上り面、
LiDAR外部パラメータ、床の高さを確認する。JSONを読み込めない場合の
C++フォールバック地図も、JSONと同じ名目形状へ更新した。

## 実装確認

地図JSONとC++フォールバックの35物体が一致すること、机8箱、
フェンス外形x=±5.40 m・y=±5.85 m、表示専用土台4個を自動テストで確認した。
インストール済みノードから`/field_map_markers`を実際に購読し、35個すべてが
`map`フレームで単位姿勢として配信されることも確認した。
決勝bagのLiDAR・IMUのみを2倍速で再生しても180秒区間の融合姿勢は
1,795件配信され、最大配信間隔は約0.200秒だった。点群への適合度と
実フィールドの絶対寸法精度は別の評価である。
